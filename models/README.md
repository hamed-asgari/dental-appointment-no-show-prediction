# Model artifacts

## Current status

Version `1.0.0` did not persist a reusable preprocessing pipeline, estimator,
calibrator, probability policy, or inference artifact. The selected final
candidate was a constant population prior and provided no appointment-level
ranking.

Model persistence is therefore part of the Version `2.0.0` recovery scope, not
a completed Version `1.0.0` deliverable.

Any future artifact must be:

- generated by a documented reproducible command;
- accompanied by machine-readable metadata;
- tied to a frozen feature contract and evaluation policy;
- load-tested in the automated test suite;
- suitable for the evidence-based application type;
- explicitly marked as trained only on fully synthetic data;
- excluded from claims of clinical or operational validity.

Large or environment-specific artifacts should not be committed automatically.
The repository must document whether the final artifact is versioned directly,
published as a release asset, or regenerated from source.

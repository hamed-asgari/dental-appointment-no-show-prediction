## Relationship to Version 1.0.0

Version `1.0.0` remains an immutable methodological and audit checkpoint. Its
selected `calibration_prior` assigns one constant pre-test probability to every
appointment and therefore provides no appointment-level ranking. Its historical
release record, tag, changelog section, and limitations are preserved verbatim.

Version `2.0.0` completes the portfolio recovery without rewriting Version 1.
It adds a deterministic longitudinal synthetic benchmark, strict prediction-time
as-of features, rolling-origin model comparison, a one-time protected final-test
evaluation, frozen reporting artifacts, and a read-only Streamlit evaluation
dashboard.

## Version 2 protected-test result

The pre-frozen selected model is uncalibrated Logistic Regression. On the
one-time protected 2027 final test:

- rows: `4,343`;
- positives: `358`;
- prevalence: `0.082431498964`;
- average precision: `0.147157699598`;
- ROC AUC: `0.630029510104`;
- Brier score: `0.076205245350`;
- log loss: `0.282623134261`.

The constant-prior comparator has average precision `0.082431498964`, Brier
score `0.075687251878`, and log loss `0.284986831062`. The model therefore
improves ranking and log loss but has a slightly worse Brier score than the
prior comparator. Under the pre-frozen app gate, that mixed calibration result
selects `transparent_model_evaluation_dashboard` rather than an individualized
risk calculator.

## Portfolio application

The Streamlit application is an evidence-driven, read-only model-evaluation
dashboard. It consumes only frozen R3 reporting artifacts, verifies artifact
integrity, and presents protected-test performance, calibration/capacity views,
interpretation, and limitations. It does not perform runtime patient scoring,
model refitting, threshold selection, or post-test tuning.

## Limitations

All appointment and patient data are synthetic. The project has no external
clinical validation and does not establish real-world transportability,
clinical effectiveness, fairness, or patient-level safety. The protected final
test was accessed exactly once under the frozen R3 protocol and must not be
reused for model, calibration, feature, or threshold changes.
